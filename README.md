# RackNotes

Теренен опис на клиентско оборудване: шкафове по U, устройства, помещения и снимки — на телефона, без връзка. После справки от компютър и импорт в **NetBox 4.1.11**.

> Статус: **етап 1 (0.7)** — теренният опис работи офлайн на едно устройство. Синхронизация на екипа, каталог от NetBox и експорт следват — виж [docs/ROADMAP.md](docs/ROADMAP.md).

## Какво прави сега

- Огледи по клиент (NetBox Tenant) и обект (Site), с автор и статус.
- Етажи и помещения (NetBox Locations).
- Шкаф по U с лице и гръб; докосваш свободно място и добавяш устройство на него.
- Устройство: производител, модел, роля, име, U, страна, дълбочина, сериен №, инвентарен №, IP, бележки, снимки; статус „за проверка“ или „потвърдено“.
- Проверка за застъпване в шкафа; предложения от вече въведени модели (височината в U се попълва сама).
- Сканиране на баркод за сериен № в Chrome на Android (iPhone — ръчно въвеждане).
- Работи без интернет (PWA); снимките се компресират до 1600 px JPEG.
- Архив в JSON (със снимките) за пренос и резервно копие.

## Технологии

| Част | Избор | Защо |
|---|---|---|
| Приложение | Svelte 5 + TypeScript + Vite | малко и бързо на телефон |
| Офлайн | IndexedDB (Dexie), Workbox | данните са на устройството първо |
| Сървър | Cloudflare Worker + Hono | безплатно; същият код ще върви и в контейнер |
| Вход | Cloudflare Access (код по имейл) | безплатно до 50 души, без промени в кода |

## Разработка

Нужни са Node.js 20+ и npm.

```bash
npm install
npm run dev        # http://localhost:5173 — само приложението
npm test           # логика на шкафа
npm run check      # типове
npm run build && npx wrangler dev   # приложение + API, както в Cloudflare
```

Структура:

```
src/core/     модел на данните и логика на шкафа (без I/O, с тестове)
src/web/      приложението (views/, lib/)
src/worker/   Cloudflare Worker — /api/*
tests/        unit тестове
docs/         пътна карта и инсталиране
```

## Инсталиране в Cloudflare

Виж [docs/DEPLOY.md](docs/DEPLOY.md) — около 10 минути, без разход.

## Данни и сигурност

В repo-то няма данни от огледи, ключове или адреси на клиенти. На етап 1 всичко остава в браузъра на устройството. Изтегляй архив след всеки оглед.
