# RackNotes

Теренен опис на клиентско оборудване: шкафове по U, устройства, помещения и снимки — на телефона, без връзка. После справки от компютър и импорт в **NetBox 4.1.11**.

*Offline field survey of client racks for MSPs: import from NetBox 4.1.11, walk the site on your phone, no signal needed.*

> Статус: **0.17** — опис на терен без връзка, синхронизация на екипа, внос от NetBox и проверка на обект на място, план на етажа и 3D. **Експортът към NetBox (CSV) още го няма** — виж [docs/ROADMAP.md](docs/ROADMAP.md).

**Защо не просто NetBox?** NetBox е източникът на истина, но в сървърното на клиента често няма мрежа, а формите му не са за телефон в една ръка. RackNotes взима данните от NetBox, проверяваш ги на място без връзка, а екипът ги синхронизира после.

## Какво прави сега

- Огледи по клиент (NetBox Tenant) и обект (Site), с автор и статус.
- Етажи и помещения (NetBox Locations).
- Шкаф по U с лице и гръб; докосваш свободно място и добавяш устройство на него.
- Устройство: производител, модел, роля, име, U, страна, дълбочина, сериен №, инвентарен №, IP, бележки, снимки; статус „за проверка“ или „потвърдено“.
- Проверка за застъпване в шкафа; предложения от вече въведени модели (височината в U се попълва сама).
- Сканиране на баркод за сериен № в Chrome на Android (iPhone — ръчно въвеждане).
- Работи без интернет (PWA); снимките се компресират до 1600 px JPEG.
- Синхронизация между устройства: промените чакат без връзка и се изпращат сами; конфликтите се показват поле по поле.
- Архив в JSON (със снимките) за пренос и резервно копие.
- Внос от NetBox (шкафове, устройства, кабели) и **проверка на обект на място**: всяко устройство се отбелязва „съвпада“, „различно“ или „липсва“, а разликите излизат като CSV.
- Каталог от [devicetype-library](https://github.com/netbox-community/devicetype-library) (14 000+ модела) с изгледи отпред и отзад, и офлайн.
- План на етажа от PDF или снимка, с мащаб; помещения, шкафове, врати и предмети (камери, четци) върху плана; 3D изглед на помещението.
- **Местене в шкафа** (↑/↓ 1U, лице/гръб или докосване на свободно място), местене в друг шкаф заедно със съдържанието; тави и рафтове с няколко устройства в 1U.
- „Изчисти това устройство“ в Настройки: трие данните на клиентите от телефона и изписва.

## Технологии

| Част | Избор | Защо |
|---|---|---|
| Приложение | Svelte 5 + TypeScript + Vite | малко и бързо на телефон |
| Офлайн | IndexedDB (Dexie), Workbox | данните са на устройството първо |
| Сървър | Cloudflare Worker + Hono | безплатно; същият код ще върви и в контейнер |
| Вход | Cloudflare Access (код по имейл) | безплатно до 50 души, без промени в кода |

## Разработка

Нужни са Node.js 20+ и npm.

```bash
npm install
npm run dev        # http://localhost:5173 — само приложението
npm test           # логика на шкафа
npm run check      # типове
npm run build && npx wrangler dev   # приложение + API, както в Cloudflare
```

Структура:

```
src/core/     модел на данните и логика на шкафа (без I/O, с тестове)
src/web/      приложението (views/, lib/)
src/worker/   Cloudflare Worker — /api/*
tests/        unit тестове
docs/         пътна карта и инсталиране
```

## Инсталиране в Cloudflare

Виж [docs/DEPLOY.md](docs/DEPLOY.md) — около 10 минути, без разход.

## Данни и сигурност

В repo-то няма данни от огледи, ключове или адреси на клиенти. Данните са в Cloudflare D1 с юрисдикция ЕС, зад Cloudflare Access; тестовите версии ползват отделни бази. Какво се събира, колко се пази и как се трие — в [docs/PRIVACY.md](docs/PRIVACY.md).
